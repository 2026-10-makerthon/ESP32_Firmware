손실 주입 시험과 정상 무선 누락률 시험을 섞지 마세요. 조용해서 sample_index가 건너뛴 구간은 손실률에서 제외하고 frame_seq 기준으로 셉니다. 첫 수신 이전 누락은 시작 seq 또는 장치의 dropped 계수로 보완해야 합니다. 전송하지 않은 오래된 pre-roll도 selected 후 폐기되었다면 dropped로 기록합니다.

서로 다른 장치의 시계를 직접 빼서 지연을 계산하지 마세요. GET_STATE/HEARTBEAT 왕복 구간으로 오프셋·오차 범위를 추정하거나 공통 계측 장치를 사용합니다. 드라이버 로그만으로 실제 촉각 발생 시각을 주장하지 않습니다. 이 저장소의 자동 PC 도구는 지연 p95를 자동 합격 처리하지 않습니다.
