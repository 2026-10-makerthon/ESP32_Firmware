# 현재 배선: XIAO ESP32-S3 + INMP441 + DRV2605L

2026-10-31: 배선은 그대로 두고 DM161을 DC ERM으로 가정한3V 목표 초기 구동 프로파일 `profiles/xiao-dm161-3v-prototype.json`을 추가했다. DRV 전원3.3V,명목 평균 출력 약2.98V,기동 boost OFF,signed RTP로 기존 패턴을 실행한다. `-PhysicalHaptic` 빌드에서 실제 출력이 활성화되며 실물 검증 완료 표시는0이다. 아래의 기존 미확정 프로파일은 로그 전용 시험에 계속 사용한다.

2026-10-30 사용자가 제공한 배선표가 현재 펌웨어의 기준이다. INMP441 WS=D0/GPIO1, SCK=D1/GPIO2, SD=D3/GPIO4, L/R=GND. DRV2605L SDA=D4/GPIO5, SCL=D5/GPIO6. 버튼은 D8/GPIO7–GND. 마이크와 드라이버 전원은 3V3/GND, 모터는 드라이버 OUT+/OUT−, 1S LiPo는 XIAO BAT+/BAT−다. 코인 모터 종류·정격·피크전류·드라이버 보정값은 아직 미확정이다.

현재 프로파일은 `profiles/xiao-inmp441-drv2605l.json`이며 실제 출력은 비활성화되어 있다. 자세한 동작·제약은 [XIAO 사용법](../docs/XIAO_OPERATION.ko.md)을 따른다. 버튼 OFF는 딥슬립이며 배터리를 물리적으로 차단하지 않는다. 아래 SuperMini/EM-MA-126 내용은 이전 후보의 기록이고 현재 XIAO 배선과 섞어 사용하지 않는다.

# 이전 후보 기록: ESP32-S3 SuperMini 배선·배터리 설계안

> 구매 방침 수정: 사용자는 부품 수를 줄이고 보드 USB-C 충전을 사용하기를 원한다. 내장 충전회로가 있는 보드인지 실물 앞·뒷면/판매 자료를 먼저 확인하고, 아래 외부 충전기 4410 구매는 보류한다. NoLogo 문서에는 B+/B− 배터리 연결과 USB 충전 지원이 명시되어 있다. 일치하는 보드라면 배터리는 보드 B+/B−에 연결하고 모터용 5V 승압기만 별도 사용하는 축소안을 검토한다. 모터용 승압기 출력은 보드 5V/USB 전원선과 병렬 연결하지 않는다. 보드 충전전류와 배터리 허용 충전전류를 확인한 뒤 배선을 확정한다. 아래 외부 충전기 구성은 대안이며 필수 구매 목록이 아니다.

## 현재 우선안: 내장 충전회로 사용

사용자가 구매한 승압기는 BRIDGE 판매의 5/8/9/12V A·B 솔더 점퍼 선택형 미니 모듈이다. 제공 상품 설명 사진 `1-28735.jpg`에는 아무것도 납땜하지 않은 기본 출력이 12V라고 적혀 있다. 이전 Pololu 부품은 구매 부품이 아니다. 외형이 비슷한 타사 모듈은 점퍼 논리 설명이 다르므로 해당 실물의 표를 따른다. 전원을 분리한 상태에서 5V 설정으로 변경하고, 부하를 연결하지 않은 OUT+/OUT−에서 약 5.0V를 측정한 뒤 모터를 연결한다. 실제 점퍼 상태와 출력 전압은 아직 확인하지 않았다.

적용 조건: 실물 보드가 1S 3.7V LiPo 충전을 지원하고, B+/B− 패드와 배터리에 맞는 충전전류가 확인된 경우다. 보드 실물 사진은 아직 제공되지 않았으므로 패드의 물리 위치는 확정하지 않는다.

```text
보호회로 내장 1S 배터리 (+) ──┬── SuperMini B+
                              └── 5V 승압기 VIN / IN+
배터리 (-) ──────────────────┬── SuperMini B− / GND
                              └── 5V 승압기 GND / IN−

승압기 VOUT / OUT+ (5V) ───────── EM-MA-126 VCC
공통 GND ─────────────────────── EM-MA-126 GND
SuperMini GPIO1 ───────────────── EM-MA-126 IN [3.3V 입력 호환 확인 후]

SuperMini 3V3 ─────────────────── INMP441 VDD / VCC
SuperMini GND ─────────────────── INMP441 GND 및 L/R
SuperMini GPIO7 ───────────────── INMP441 SCK
SuperMini GPIO8 ───────────────── INMP441 WS
SuperMini GPIO9 ───────────────── INMP441 SD
```

INMP441은 왼쪽 슬롯을 사용한다. 승압기 출력 GND가 별도로 있는 모듈은 이를 공통 GND에 연결한다. 승압기 5V 출력을 보드 5V, B+, 3V3에 연결하지 않는다. 배터리를 보드 3V3에 직접 연결하지 않는다. 승압기 출력은 모터를 연결하기 전에 5.0V인지 측정한다.

USB-C는 보드의 충전용 입력을 사용한다. IN 입력의 허용전압·정지 극성과 충전 중 부하 처리 방식은 아직 미확인이다. 충전하면서 모터를 동작시키는 운용은 전원 회로 확인 뒤 정한다. 아래 상세 마이크 배선과 모터 전원 커패시터 지침도 적용한다.

아래는 최초 외부 충전기 대안과 부품별 상세 설명이다. 현재 우선안과 두 전원 구성을 섞어 연결하지 않는다.

설계일: 2026-10-29. 실물 연결·전류·보드 리비전은 미검증이다. 사용자 제공 사진에서 모터 모듈을 **EM-MA-126**으로 식별했다. 사진의 사양은 정격 5.0V, 작동 3.0~5.3V, 정격전류 MAX 60mA, 동작전류 MAX 90mA, 크기 21×30mm이며 IN/VCC/GND 단자는 사용자가 확인했다. 앞서 사용자가 알려준 시작전압 3.7V는 이 사진에는 별도로 적혀 있지 않다. 공급전압은 **5.0V**로 정한다.

## 선정안

| 부분 | 선정 |
|---|---|
| 보드 | ESP32-S3 SuperMini; 아래 번호는 GPIO 번호이며 물리 핀 순서/XIAO D번호가 아님 |
| 마이크 | INMP441 6핀 I2S 브레이크아웃, 보드 3V3에서 공급 |
| 배터리 | 보호회로 내장 1S LiPo 3.7V **2000mAh**, 완충 4.2V, 연속 방전 허용 **2A 이상**인 제품 |
| 충전기 | Adafruit Micro-Lipo USB-C 4410, 제조사 지침에 따라 **500mA**로 설정 |
| 승압기 | Pololu U3V40F5, 출력 5V. 출력 허용전류는 입력전압·온도별 제조사 그래프와 실제 기동 시험으로 확인 |
| 전원 스위치 | 배터리 측 DC 3A 이상 정격의 기계식 스위치 |
| 모터 제어 | 모듈의 IN에 GPIO1 사용 예정. 3.3V 입력 호환 확인이 직접 연결 조건 |

2000mAh는 초기 제작용 용량 제안이다. 사진의 동작전류 MAX 90mA를 모터 전력 예산에 반영한다. 이는 기동/구속 순간전류 측정값을 뜻하지 않는다. 이 기본안의 총 5V 부하 설계 예산은 0.8A 이하로 잡는다. 배터리 3.0V, 변환효율 85% 가정 시 배터리 전류는 약 1.57A다. 모터 기동 시 이 예산을 넘으면 배터리·배선·전원부 정격을 다시 선정한다. 보호회로의 차단전류를 셀의 허용 방전전류로 대신 사용하지 않는다. 실제 사용시간은 미측정이다.

## 마이크 배선

| INMP441 | SuperMini |
|---|---|
| VDD / VCC | 3V3 |
| GND | GND |
| SCK / BCLK | GPIO7 |
| WS / LRCLK | GPIO8 |
| SD / DOUT | GPIO9 |
| L/R | GND — 왼쪽 채널 |

VDD–GND에는 마이크 가까이 0.1µF 세라믹, 전원 입구에 10µF를 배치한다. SD–GND에는 100kΩ 풀다운을 연결한다. 모듈에 이미 실장된 부품은 확인 후 중복 생략 가능하다. CHIPEN이 별도 노출되어 있으면 VDD에 연결한다. MCLK는 필요 없다. 마이크에 5V나 배터리 전압을 직접 넣지 않는다.

펌웨어는 기존 GPIO7/8/9를 유지할 수 있다. I2S master RX, Philips I2S, 16kHz, 각 32비트인 좌우 슬롯으로 수신하고 왼쪽 데이터를 사용한다. INMP441 데이터는 24비트이며 프레임당 64클록이 필요하다. 따라서 16kHz에서 BCLK=1.024MHz다.

## IN/VCC/GND 모터 모듈 배선

| 모터 모듈 | 연결 |
|---|---|
| VCC | 승압기 5V — 사진의 모듈 정격전압과 일치 |
| GND | 공통 GND |
| IN / PWM | GPIO1 — **3.3V 로직 입력 호환 확인 후** 연결 |

모듈의 PWM 입력 허용전압·극성·주파수·기본 정지 상태는 아직 미확인이다. 5V 전원 사양만으로 3.3V 입력 호환을 추정하지 않는다. IN에 5V 신호가 필요하면 입력 사양에 맞는 3.3V→5V 로직 버퍼를 추가한다. ESP32 GPIO에 5V를 넣지 않는다.

외부 MOSFET과 모터 양단 다이오드는 이번 기본안의 추가 구매 부품에서 제외한다. 모듈 내부 드라이버/보호회로는 모델 자료로 확인한다. 모터 모듈의 VCC–GND에 220µF/10V 전해와 0.1µF 세라믹을 가까이 배치한다. 전원 상한 5.3V를 지킨다.

IN의 HIGH가 ON이고 LOW가 OFF인 것으로 확인되면 IN–GND에 10kΩ 풀다운을 배치한다. 반대 극성이라면 정지 바이어스를 다시 정한다. PWM 주파수, 최소 기동 duty, 약/강 duty, 기동 펄스는 모듈 자료와 실제 측정 후 확정한다. 단순히 시작전압을 PWM duty 비율로 환산해 확정하지 않는다.

## 배터리·전원

```text
USB 5V ── Micro-Lipo 4410 충전기 USB-C
                    │ JST 배터리 단자
             보호회로 내장 1S LiPo 3.7V 2000mAh
                    │
충전기 BAT ── 전원 스위치 ── 승압기 VIN
                               │ VOUT 5.0V
                               ├── SuperMini 5V 핀
                               └── 모터 전원 / 모터 모듈 VCC

SuperMini 3V3 ── INMP441 VDD
배터리 (-), 충전기 GND, 승압기 GND, 보드 GND, 드라이버 GND: 공통
```

- 충전기 BAT는 배터리 전압 단자이며 충전기 5V 단자와 다르다. JST-PH 커넥터도 실제 +/− 극성을 확인한다.
- 승압기 VIN–GND에 47µF/10V 전해, 보드 5V–GND에 100µF/10V를 가까이 추가한다. 전해 커패시터 극성을 지킨다.
- 승압기 출력에서 보드와 모터로 전원선을 각각 분기하고 모터의 접지 귀환이 마이크 배선을 통과하지 않게 한다.
- **충전할 때는 전원 스위치 OFF**로 하고 외부 충전기의 USB-C를 사용한다. 이 기본안은 충전하면서 장치를 구동하는 구성이 아니다.
- **보드 USB-C로 업로드할 때는 전원 스위치 OFF, 승압기→보드 5V 선도 커넥터/점퍼로 분리**한다. 보드 USB와 외부 승압 출력을 병렬 연결하지 않는다. 배터리 동작 시험은 USB를 빼고 5V 선을 복구한 뒤 BLE로 수행한다.
- EN만 끄면 부하 전원이 완전히 차단되는 것으로 가정하지 않는다. 이 승압기는 비활성 상태에도 입력이 출력으로 통과할 수 있으므로 배터리 측 기계식 스위치를 사용한다.
- 이번 기본안은 SuperMini의 B+/B−를 사용하지 않는다. NoLogo 문서에는 내장 충전 기능이 있지만 사용자 실물의 충전 IC·전류·전원 회로와 일치하는지는 미확인이다. 실물 회로를 확인하면 부품을 줄일 수 있다.
- 배터리 4.2V를 보드 3V3·마이크에 직접 연결하지 않는다. 2셀 7.4V, LiFePO4, 4.35V 완충 LiHV는 이 충전기에 사용하지 않는다.

모터는 마이크와 기계적으로 떨어뜨려 고정하고 마이크 음구를 가리지 않는다. 전원 분리·커패시터만으로 모터 자체의 진동 소음이 없어지지는 않는다.

## 검증 상태

모터 단자 IN/VCC/GND는 사용자에게 확인했고, 정격전류 MAX 60mA와 동작전류 MAX 90mA는 제공 사진과 판매자 상품설명에서 확인했다. 기동/구속 순간전류, IN의 3.3V 입력 호환, 입력 극성/주파수는 아직 미확인이다. 사진에 적힌 저항 10MΩ은 측정 대상/조건이 없어 모터 권선저항이나 IN 입력저항으로 사용하지 않는다. 실제 배선 전 보드 실크의 GPIO 번호와 5V 핀을 확인하고, 부하 없는 출력전압 → 마이크 단독 → 기본 모터 OFF → 짧은 기동 → BLE/진동 동시 시험 순서로 확인한다. 5V는 모터 허용 상한 5.3V를 넘지 않아야 한다.

현재 유일한 `profiles/unverified.json`은 이전 XIAO 후보의 비활성 프로파일이다. 이번 작업은 배선 문서만 갱신했으며 실제 출력은 OFF다. 확인한 자료·배선·전류·정지 동작·duty 측정을 verification_record에 남긴 뒤 실물용 프로파일을 만든다.
